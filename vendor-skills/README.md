# OKX Agent Skills

Ana entegrasyon `.mcp.json` içindeki resmi OKX Agent Trade Kit HTTP MCP bağlantısıdır. Bu klasör kod veya ikinci bir MCP sunucusu içermez; yalnızca yarışma sırasında kullanılan resmi skill adları ve allowlist notları için ayrılmıştır.

Write allowlist: spot place/cancel, grid create/stop ve yalnızca risk azaltıcı sell.

Kesin denylist: swap, futures, options, earn, transfer, withdraw ve leverage write.
